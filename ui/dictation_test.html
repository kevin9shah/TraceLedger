What a pass looks like

  • Dictated text appears in full, with no dropped or reordered words.
  • Injected > 0 after dictating — the insertion path works; or Clipboard inserts > 0 without you pressing Cmd+V, which is how Wispr Flow and similar tools insert on macOS. Either counts as a pass.
  • Typing still raises keydown and inserts normally.
  • The focus ring is clearly visible on the field being dictated into.
