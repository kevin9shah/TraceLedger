# BENCHMARK RESULTS

> **Generated by `scripts/run_benchmark.py` from real runs. Never hand-written.**
>
> **Preliminary results on 25 synthetic cases. Not evidence of production performance.** Business records are synthetic and their realism has not been reviewed by a domain expert (RISKS.md P15). The chain facts are real Polygon transactions.

## Read this before quoting any number below

**`traceledger_deterministic` scores 100% on outcome accuracy, and that is a warning, not an achievement.** The cases and the system were authored by the same party, so this measures whether the code does what its author intended -- not whether it handles reality. A benchmark the system passes perfectly has stopped discriminating. Treated as a limitation (RISKS.md P16), not as evidence of quality.

Why the figure is inflated:

- Cases were written knowing which checks exist, so each one happens to be answerable by one of them.
- The deterministic layer cannot fabricate an evidence ID -- construction raises -- so the citation metrics are true by design rather than earned.
- 25 cases cannot distinguish 100% from, say, 92% (P12).
- No adversarial cases from an independent author, and no realism review by someone with domain knowledge (P15).

**What is meaningful is the comparison of failure modes** between the two systems, and the `rules_only` misses below, which are concrete and reproducible. The wrong-asset catch is separately verifiable against live mainnet, independently of this benchmark.

## Systems compared

| System | What it is |
|---|---|
| `rules_only` | Our implementation of a conventional reconciler: matches assets by **ticker symbol**, compares amounts at 2dp as floats, finds payments by scanning Transfer events, always answers. Not any vendor's product. |
| `traceledger_deterministic` | TraceLedger's deterministic layer only: token identity by contract address, decimals read from the contract, integer base-unit arithmetic, receipt status checked, may answer `unresolved`. **The LLM layer is not yet built (CP7), so this is not the full system.** |
