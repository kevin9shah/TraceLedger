Evidence Thread States

TraceLedger models settlement as an unbroken causal thread. Every state pairs a visible glyph, color, and label:

✓
Verified Fact
Proved by deterministic chain bytecode
⚠
Conflict
Direct contradiction in records vs chain
◬
Candidate / Asserted
Unproven hypothesis awaiting evidence
◌
Missing Evidence
Dashed segment; check cannot execute

How It Works: 5-Step Evidence Protocol

Stage 1
Deterministic Proof

Exact integer base-unit math. Zero float drift. Contract metadata verified on-chain.

Stage 2
Evidence Linking

Inspects multi-transfer event logs, receipt status, and destination whitelist matches.

Stage 3
Root Cause Clusters

Graph & SQL traversals group multiple payment exceptions to shared import batch errors.

Stage 4
Constrained Brief

LLM generates hypotheses strictly checked by an independent validator before display.

Stage 5
Human Audit Sign-Off

Human records decision with rationale into an append-only SQLite log (not tamper-proof).
